First release: a self-hosted replacement for Google Drive, Google Photos, and iCloud that runs on your own Mac, Raspberry Pi, or PC.

## Server (`homebackupd`)
- **Google Drive:** read-only mirror using the Drive Changes API. Google Docs, Sheets, and Slides are exported as Office files.
- **Google Photos:** imported from Google Takeout archives, deduplicated, and organized as `year/month`.
- **My Files:** a writable drive that the apps edit directly. Every edit keeps previous versions, and deleted files go to a trash for a while. An edit made from an out-of-date copy is saved as a conflict copy, so nothing is lost.
- **Device photo backup:** resumable uploads with SHA-256 verification.
- **Thumbnails:** for photos and videos. HEIC and video use sips/qlmanage on macOS or ffmpeg.
- **Network access:** HTTPS with a pinned self-signed key, Bonjour discovery, and device pairing with a 6-digit code.
- **Backup format:** plain files on disk, so you can browse your backup without this software.

## Apps
- **Mac menu bar app with Finder integration:** `HomeBackup-0.1.0-macOS.zip`, signed with Developer ID and notarized by Apple. Unzip it, move HomeBackup to Applications, and open it; it runs on any Mac with macOS 14 or newer.
- **iPhone/iPad app:** build it with Xcode for now (see the README). TestFlight is planned.

## Known limitations
- Early release: test it alongside your existing cloud accounts before relying on it.
- No off-site copy yet.
- Remote access outside the home network (for example Tailscale) is not built in yet.
