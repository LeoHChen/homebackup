Making the server easier to run and the Mac app easier to understand.

## Server (`homebackupd`)
- **Web dashboard** at `https://<server>:8420/`: storage, each backup's size and state, a getting-started checklist, Files and Photos browsing with thumbnails, download, previous versions and trash restore, uploads and folders in My Files, paired devices with revoke, recent Activity, and Settings. Pair the browser with a code like any other device.
- **Pairing codes from any paired device:** `POST /api/v1/pair/codes`. Only the first device ever needs `homebackupd pair` on the server.
- **Richer status:** `GET /api/v1/status` now reports disk space, per-source file counts and sizes, trash size, retention, and the paired-device count.
- **Recent log in memory:** `GET /api/v1/log` returns the last lines, including TLS handshake errors from the HTTP server.
- The startup log prints the dashboard URL; `homebackupd pair` mentions it too.
- `make sign` signs the macOS binary with a Developer ID, so macOS keeps the removable-volume permission across updates instead of asking on every new build. The README's update steps now replace the binary as a fresh file; overwriting it in place breaks its signature.

## Mac app
- **Fixes pairing on macOS 15 and later.** The app and its Finder extension now share a Team-ID-prefixed app group (`<TEAMID>.com.github.leohchen.homebackup`), which macOS accepts without a provisioning-profile entry and which also works as the keychain access group for the device token. Before, the token could only be saved in the login keychain, where the Finder extension could not read it, and macOS could prompt that HomeBackup "wants to access data from other apps". **After updating, pair the Mac again** (menu → Connect to your home server…); the Finder locations are created again.
- Explains when macOS has the File Provider extension turned off ("Finder can't show your files yet") and opens System Settings to the right place.
- Plain-language errors instead of raw error text: unreachable server, revoked device (with **Pair again**), key mismatch.
- Shows free space on the backup drive and each backup's state; **Pair another device…** shows a code for an iPhone, another Mac, or a browser; **Open dashboard**.
- Pairing window walks through three steps, explains when no server is found, and says what to expect after pairing.

## Shared Swift library
- `UserMessage.describe` turns errors into sentences for people; `status()`, `newPairCode()`, `devices()`, `revokeDevice()`.
